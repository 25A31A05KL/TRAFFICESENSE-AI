1. Run starter app and verify frontend + REST endpoints.
2. Improve simulation: lanes, intersections, route-following and multiple vehicle types.
3. Add WebSocket broadcasts for live state.
4. Persist entities using Spring Data JPA repositories.
5. Add calibrated computer-vision models and test datasets.

8. Add digital-twin scenario editor and comparison reports.
9. Add assistant with strict API-grounded answers.
10. Add tests, deployment, documentation and demo recording.

Suggested student schedule: 8–12 weeks depending on prior Java/Spring/AI experience.
